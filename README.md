# Seat and Set (Sprint 2)

Cross-platform mobile application built with Flutter, Dart, and Firebase.

## Getting Started

This project is a starting point for the Seat and Set Flutter application.

### Tech Stack
- **Dart**: Core programming language
- **Flutter**: Cross-platform UI framework
- **Firebase Auth**: User identity & session management
- **Cloud Firestore**: Real-time NoSQL database
- **Firebase Storage**: Media & asset storage
- **Emulator / Device**: Android virtual device
